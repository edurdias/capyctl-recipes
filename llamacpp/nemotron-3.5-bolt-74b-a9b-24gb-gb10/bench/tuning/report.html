Method

  • Every request is a streaming chat completion sent to the CapyCTL inference endpoint with stream_options.include_usage; token counts come from the final usage chunk.
  • Time to first token (TTFT): request sent to the first chunk carrying content or reasoning text.
  • Generation tok/s: (completion tokens − 1) / (last token chunk − first token chunk). TPOT is the inverse, in milliseconds per token.
  • Prompt processing tok/s: prompt tokens / TTFT. It includes queueing and the first decode step, so it understates the engine's raw prefill rate at short prompts.
  • Total time: request sent to the end of the stream.
  • Output bytes per second: UTF-8 bytes of content and reasoning text over the generation window.
  • Peak memory: the highest value the memory command printed while the request or round ran.
  • Context sweep: one request at a time. Each request gets its own deterministic filler text (a different seed per run), so no run reuses another's prefix cache. The prompt length is sized from two calibration requests; the table shows the prompt tokens the engine reported. k is 1000 tokens.
  • Concurrency: N requests start together from a fixed prompt set; aggregate tok/s is the round's completion tokens over the time from the first request sent to the last stream finished. Per-stream tok/s is the median over every request at that level; TTFT p50/p95 likewise.
  • Each chart point is a median. Tables show the median with the min–max range across runs below it.

The series differ in model, context sweep settings, concurrency settings. Compare them with that in mind.
