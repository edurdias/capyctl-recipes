# CapyCTL recipes — working agreement

Rules for every contributor, human or coding agent.

## Keep published material neutral

Never name the downstream platforms, services or customers that run CapyCTL or these
recipes, or their internal identifiers (recipe, build or node IDs). This covers every
tracked file (READMEs, model cards, scripts, comments, configs, results and logs), commit
messages, pull request titles and bodies, issues, and anything published from here, such
as model cards on Hugging Face. Describe such a setup by what it is: "a production SGLang
recipe", "another workload's engine (33 GiB) was resident", followed by its flags or
numbers.
